# Next Step: Link Your Project

## ✅ You're Logged In!

Now link your project to set up the webhook automatically.

---

## Run This Command:

```cmd
npx vercel link
```

---

## What Will Happen:

1. **It will ask:** "Set up and deploy?" → Type `Y` and press Enter
2. **It will ask:** "Which scope?" → Select your account/team
3. **It will ask:** "Link to existing project?" → Type `Y` and press Enter
4. **It will list projects:** Select `product-brands` (use arrow keys and Enter)
5. **It will ask:** "What's your project's name?" → Press Enter (default is fine)
6. **It will ask:** "In which directory is your code located?" → Press Enter (./ is correct)

---

## This Will:

✅ Link your local project to Vercel  
✅ Set up the GitHub webhook automatically  
✅ Enable auto-deploy  
✅ Configure everything properly  

---

## After Linking:

1. **Check GitHub webhooks:**
   - Go to: https://github.com/cristhianrodriguez1991/ProductBrands/settings/hooks
   - You should see a Vercel webhook now!

2. **Test auto-deploy:**
   - Make a small change
   - Push to main
   - Watch Vercel auto-deploy!

---

## Run Now:

```cmd
npx vercel link
```

Follow the prompts and select your `product-brands` project!
