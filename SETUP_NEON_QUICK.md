# ⚡ Quick Neon Setup Guide (2 Minutes)

## Step-by-Step:

### 1. Go to Neon
**Visit:** https://neon.tech

### 2. Sign Up
- Click "Sign Up" (top right)
- Sign up with GitHub (easiest) or email
- Verify email if needed

### 3. Create Project
- Click "Create a project"
- **Name:** `product-brands`
- **Region:** Choose closest (US East if in US)
- **PostgreSQL:** Latest version
- Click "Create Project"

### 4. Copy Connection String
- Wait ~30 seconds for project to create
- You'll see a connection string like:
  ```
  postgresql://user:pass@ep-xxxxx.aws.neon.tech/neondb?sslmode=require
  ```
- **Click "Copy"** button

### 5. Save It!
- Paste the connection string somewhere safe
- You'll need it to add to Vercel as `DATABASE_URL`
