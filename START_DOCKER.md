# Start Docker Desktop

Docker Desktop needs to be running before we can use it.

## Quick Start

1. **Open Docker Desktop:**
   - Search for "Docker Desktop" in the Windows Start menu
   - Click to launch it
   - Wait for Docker to fully start (you'll see a whale icon in the system tray)

2. **Verify it's running:**
   - The Docker Desktop window should be open
   - The system tray icon should show Docker is running
   - You can check by running: `docker ps` in PowerShell

3. **Once Docker Desktop is running, let me know and I'll:**
   - Start the PostgreSQL database
   - Set up the database schema
   - Seed with demo data
   - Start the development server

## Alternative: Start via Command

If Docker Desktop is installed but not running, you can try:
```powershell
Start-Process "C:\Program Files\Docker\Docker\Docker Desktop.exe"
```

Or search for "Docker Desktop" in the Start menu and click it.

## After Docker Desktop Starts

Once you see the Docker Desktop window and the whale icon in the system tray, tell me and I'll continue with the setup!
