# Process Images

Add your process step images to this directory. The images will be displayed when users expand each step in the process flowchart.

## Required Images

Place the following images in this directory:

1. **discovery.jpg** - Image for the Discovery step
2. **sourcing.jpg** - Image for the Sourcing step
3. **samples.jpg** - Image for the Samples step
4. **branding.jpg** - Image for the Branding step
5. **production.jpg** - Image for the Production step
6. **fulfillment.jpg** - Image for the Fulfillment step

## Image Specifications

- **Format**: JPG, PNG, or WebP
- **Recommended size**: 800x600px or larger
- **Aspect ratio**: 4:3 or 16:9
- **File size**: Under 500KB for best performance

## Current Behavior

If an image is not found, a placeholder with an icon will be displayed instead. The placeholder shows which image file is expected.
